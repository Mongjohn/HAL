Import / export settings

Export saved TV settings, or choose parts of a HAL settings JSON file to import. Browser drafts are not exported. Uploaded artwork and appearance settings are not included.

Camera addresses and integration logins can contain passwords or tokens. Those choices start unchecked. Files are not encrypted.

Slideshow artwork

On the TV, open HAL settings → Background and enable Artwork slideshow and Use local artwork. JPEG, PNG, or WebP, up to 8 MB each.
